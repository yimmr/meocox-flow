# 六层架构输入输出契约与端到端流转推演

## 一、 六层架构双向流转契约矩阵

| 架构层级 | 核心模块组成 | 工程职责与系统边界 | 下行输入 / 上行输出 |
| :--- | :--- | :--- | :--- |
| **L1 交互控制平面层** | 三级介入入口、双栏协同画布（Canvas）、声明式生成式 UI（A2UI）、中途切轨条（Steer）。 | 充当人类“导演”指挥台：采集多模态意图、动态渲染参数选择卡、实时同步画布手动修改并展示透明执行轨迹。 | **下行**：自然语言意图、点选参数、中途纠偏指令、画布编辑状态。<br>**上行**：流式进度、生成式交互卡片、多轨产物实时预览。 |
| **L2 导演编排中枢层** | 规划模式门禁（Plan Gate）、混合编排引擎、分级模型路由器（端云协同分流）。 | 战略决策大脑：解析全局创意意图、拆解分镜与节奏大纲（Beat Sheet）、按复杂度路由算力并守护主上下文纯净度。 | **下行**：结构化子任务契约、黑板状态更新、模型档位路由指令。<br>**上行**：阶段性交付摘要、预算预警信号、人工审批中断请求。 |
| **L3 剧组专职角色层** | 多模态共享黑板（Blackboard）、专职生成工作节点、知觉证伪者（Falser）、审美竞技场。 | 承担高噪音、高专业度的专项任务（分镜生成、配乐混音、穿帮挑刺、多方案对决），在隔离上下文中独立作业。 | **下行**：限定作用域的专职指令与只读/专项工具授权。<br>**上行**：写入共享黑板的候选资产句柄（`asset_id`）与质检报告。 |
| **L4 技能与媒体管线层** | 三级渐进式技能库（`SKILL.md`）、MCP 标准连接总线、防错型原子工具（ACI）、批处理媒体管线。 | 智能体的“专业知识库与手脚”：按需加载视听语言规范（SOP），连接外部生成模型，并通过脚本管线一次性完成本地合成。 | **下行**：标准化的 MCP 调用载荷、批处理媒体合成指令。<br>**上行**：按需展开的技能规范正文、新生成的媒体资产句柄。 |
| **L5 安全护栏与沙箱层** | 原始资产只读防线、算力与预算守卫（Quota Guardian）、影子预演区、零凭证隔离沙箱。 | 触达物理环境与付费 API 的“安全海关”：保护用户原始素材不被覆盖、拦截超额算力消耗、在后台静默自检格式与成片。 | **下行**：受控的沙箱文件读写、经过外部代理注入密钥的 API 请求。<br>**上行**：成本预估拦截单、静态/知觉预检报错、安全审批中断。 |
| **L6 时间轴与世界观记忆层** | 单调时序状态机（UUIDv7）、非线性时间轴快照（OTIO）、设定集记忆与异步审美提炼器。 | 容错底座与长期记忆：绑定对话检查点与时间轴版本以支持“时间旅行”，跨项目沉淀角色特征锚点与创作者审美基因。 | **下行**：会话启动时的世界观设定注入、历史时间轴检查点恢复。<br>**上行**：每步执行的原子快照落盘、异步提炼的声明式审美事实。 |

## 二、 端到端闭环运转推演（30 秒宣传短片示例）

1. **记忆唤醒与意图推导（L6 → L2 → L1）**：L6 向 L2 注入历史审美偏好与产品视觉锚点；L2 在 Plan Gate 下先向 L1 推送**声明式风格与分镜确认卡**（含 3 套色板与 6 镜节奏大纲），确认前不消耗昂贵的视频生成算力。
2. **黑板立项与剧组分发（L1 → L2 → L3）**：用户点选方案后，L2 将分镜 DAG 与随机种子写入 L3 **多模态共享黑板**，并发唤醒独立上下文的“视觉生成师”与“声音设计师”。
3. **渐进式技能挂载与竞技场演练（L3 ↔ L4）**：视觉角色按需挂载《微距布光规范》与《运镜 SOP》，对核心高潮镜头开启**变体竞技场（Battle Mode）**并行生成候选片段落盘至媒体池，仅将 `asset_id` 写回黑板。
4. **中途无损切轨与对抗证伪（L1 → L3 ↔ L5）**：生成中途用户输入纠偏指令，L1 触发 **TurnSteer** 将控制帧注入队列头部，保全前序镜头并让后续镜头平滑切入新设定；同时 L3 的 **Continuity Falser** 在 L5 影子区检测出第 4 镜穿帮，自动驳回局部重绘。
5. **管线合成与时光机归档（L4 → L6 → L1）**：全部分镜达标后，组装角色通过 L4 **批处理媒体管线**一次性完成卡点裁切、调色与混音，在 L6 生成 OpenTimelineIO 时间轴快照，并在 L1 右侧画布呈现可逐轨微调的成片工程。
