# L0-L3 风险分级漏斗与状态机持久化避坑细则

## 一、 AIGC 操作风险四级管控漏斗

| 风险等级 | 典型 AIGC 动作场景 | 默认拦截与执行策略 | 配套工程保障机制 |
| :--- | :--- | :--- | :--- |
| **L0：纯感知与检索级** | 读取项目设定集、检索本地素材库标签、分析音频节拍点。 | **静默自动放行（Allow）** | 界面以折叠微状态条闪过，严格限制在授信工作区目录内读取。 |
| **L1：非破坏性虚拟编辑级** | 生成分镜文本草稿、调整时间轴虚拟切点、在影子区试套调色参数。 | **自动执行并高亮差异（Auto-Apply）** | 每次调整自动生成时间轴检查点（Checkpoint），支持随时一键撤销。 |
| **L2：高成本批量生成与导出级** | 批量调用 4K 视频生成 API、长音频克隆合成、渲染导出最终成片文件。 | **强制挂起并弹出成本审批卡（Ask Gate）** | **算力预算守卫（Quota Guardian）**先预估本次批处理的 Token 与渲染费用，人类确认明细后解锁。 |
| **L3：破坏性与越权高危级** | 覆盖/删除原始素材文件、修改系统安全配置、向未知外部地址上传私有资产。 | **物理级硬性阻断（Deny）** | 内核沙箱与前置生命周期钩子（`PreToolUse`）直接拦截，宽松模式下亦不可逾越。 |

## 二、 状态机中断与恢复（Interrupt & Resume）两大工程避坑铁律

1. **规避节点重入的非幂等副作用陷阱**：
   当状态机收到 `Resume` 指令从检查点唤醒时，主流编排框架通常会从包含 `interrupt()` 的节点函数头部重新执行至中断点。因此，**在同一个节点内，`interrupt()` 语句之前严禁包含任何非幂等副作用操作（如发起付费 API 生成、扣减额度或写入正式文件）**——必须将纯参数准备与预估计算放在中断前，将真实生成调用放在中断恢复之后。
2. **规避长周期挂起后的凭证过期（Credential Expiration）崩溃**：
   创作者可能在提交批量生成任务 5 小时后才点击“批准渲染”。状态机在序列化中断快照时必须记录外部连接的 `credential_status`，并在唤醒后真正发起调用前执行一次轻量令牌活性预检，若已过期则平缓引导刷新授权，避免批量任务在半途因 `401 Unauthorized` 损毁。
