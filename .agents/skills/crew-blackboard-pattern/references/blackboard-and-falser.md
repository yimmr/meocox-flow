# 混合编排模式对比矩阵与黑板对抗机制细则

## 一、 AIGC 五大编排模式选型矩阵

| 编排模式名称 | 控制权归属 | 在 AIGC 应用中的典型适用场景 | 核心架构优势与设计护栏 |
| :--- | :--- | :--- | :--- |
| **1. 提示词链 (Prompt Chaining)** | 确定性工程代码 | 故事梗概 → 分场剧本 → 逐镜画面描述词 → 语音台词表，每步之间设格式校验门禁（Gate）。 | 步骤高度可控、易于定位故障；中间门禁一旦发现格式不合规范立即原地拦截修复。 |
| **2. 端云分级路由 (Routing)** | 轻量分类器分流 | 语音指令转写、素材静音粗筛、简单修图指令路由至本地轻量化小模型（SLM）；复杂分镜导演路由至云端旗舰模型。 | 实现关注点分离，将高频交互延迟压缩至毫秒级心流阈值内，显著降低云端推理成本。 |
| **3. 切片并行化 (Parallelization)** | 并发调度引擎 | 已锁定设定集的 8 个独立分镜底图、多语种配音音轨同时并发发起生成请求。 | 将原本串行数十分钟的多模态生成等待时间压缩至单镜耗时；前提是子任务间无先后状态依赖。 |
| **4. 主从剧组分发 (Orchestrator-Workers)** | 导演模型动态拆解 | 面对“制作一段融合实拍素材与 AI 特效的混剪短片”等步骤未知的复杂需求，动态孵化专职子智能体。 | 将高噪音的素材搜索与局部试错彻底物理隔离在子窗口内，主脑仅接收精炼结果句柄。 |
| **5. 生成-证伪循环 (Evaluator-Optimizer)** | 证伪模型闭环控制 | 视觉生成师产出画面 → 连贯性证伪者检查人脸一致性与文字拼写 → 不达标则带精准坐标反馈重绘。 | 通过解耦“创作”与“挑刺”大幅提升成片合格率；**必须设定硬性最大重试上限（如 3 次）防止死循环烧钱**。 |

## 二、 连贯性证伪者（Continuity Falser）的四维检查清单

在设计 `Continuity Falser` 子智能体或验证环路时，应配置以下四类知觉刺探探针：
1. **角色与主体恒常性（Identity Consistency）**：对比当前分镜与黑板 `Character Bible` 中的锚点图像，检验面部五官、发型、标志性服饰色值与核心道具是否发生漂移。
2. **解剖学与物理合理性（Anatomical & Physical Plausibility）**：检测人物手部指节数量、肢体运动轨迹、物体重力下落与光影投射方向是否出现穿模或畸变。
3. **视听剪辑连贯性（Editorial & Spatial Continuity）**：检测相邻两个镜头的景别跳跃、视线方向（180 度轴线规则）与转场衔接是否生硬跳轴。
4. **多轨时间码同步（Audio-Visual Sync）**：校验口型动作、画面视觉重音切点是否与音频轨的节拍峰值（Beat Peaks）及字幕时间戳精准对齐。
